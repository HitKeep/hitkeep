# Product

HitKeep provides cookieless product and conversion analytics for product, engineering, and marketing teams. Operators can run the same application themselves or use HitKeep Cloud.

## Principles

- Keep deployment and routine administration simple.
- Show permissions, privacy controls, and destructive consequences where users act.
- Connect metrics to the pages, events, goals, and funnels they describe.
- Use consistent controls and keep information stable during refresh.

## Accessibility

Use keyboard-accessible controls, visible focus, semantic status announcements, WCAG AA contrast, and reduced-motion support. Do not rely on color alone. Localize dashboard copy for every supported locale; the locale directory and runtime configuration are authoritative.
