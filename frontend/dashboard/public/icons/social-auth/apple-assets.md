# Sign in with Apple logo images

Unaltered PNG outputs from Apple's public Sign in with Apple logo renderer, retrieved 2026-11-04 for the intended Sign in with Apple integration. Copyright Apple Inc.; Apple branding is not licensed under this repository's MIT license.

- `apple-black.png`: https://appleid.cdn-apple.com/appleid/button/logo?size=30&color=white&border=false&border_radius=0&scale=2
- `apple-white.png`: https://appleid.cdn-apple.com/appleid/button/logo?size=30&color=black&border=false&border_radius=0&scale=2

The `color` parameter selects the background; the logo is the contrasting black or white. The logo-only assets contain no text; button labels use the dashboard locale files. Neither image was traced, extracted from the JavaScript SDK, or modified.

Apple documents this renderer for its intended integration: https://developer.apple.com/documentation/signinwithapplerestapi/get-a-sign-in-with-apple-button-that-contains-just-the-apple-logo.
